Objetivo: conocer e implementar el uso del CSS

¿Qué es CSS?

CSS (Cascading Style Sheets, u Hojas de Estilo en Cascada) es la tecnología desarrollada por el World Wide Web Consortium (W3C) con el fin de separar la estructura de la presentación en un documento web.

En otras palabras: el HTML se encarga del contenido y el CSS se encarga del estilo visual (colores, tamaños, posición, tipografías, etc.).

Ejercicio 1: CSS en línea (inline)

Este párrafo utiliza el atributo style directamente dentro de la etiqueta HTML, sin necesidad de bloques <style> ni archivos externos.

Soy un párrafo con estilo en línea (inline). Mi color, fondo y alineación se definieron directamente en el atributo style.

Ejercicio 2: CSS interno (embebido)

Todo el diseño de esta página (colores del encabezado, las tarjetas blancas, los bordes, etc.) se definió usando un bloque <style></style> colocado dentro del <head> del documento, tal como se explicó en la diapositiva de la práctica.

<style type="text/css"> p { color: red; } </style>

Ejercicio 3: CSS externo

Este párrafo (y esta sección) reciben parte de su estilo desde un archivo separado llamado styles.css, enlazado con la etiqueta <link> dentro del <head>. Esta es la forma más recomendada de trabajar con CSS en proyectos reales, porque separa por completo el contenido del diseño.

Si ves este texto en cursiva, con un fondo distinto y un borde punteado, significa que el archivo styles.css se cargó correctamente. 🎉

Ventajas de usar CSS externo

  • Un solo archivo controla el diseño de todas las páginas del sitio.
  • Facilita el mantenimiento y la actualización del diseño.
  • Reduce la duplicación de código.
  • Las páginas cargan más rápido (menos código repetido).
