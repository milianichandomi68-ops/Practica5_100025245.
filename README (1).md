## Contenido

Este proyecto demuestra las tres formas de aplicar CSS a un documento HTML:

1. **CSS en línea (inline):** usando el atributo `style` directamente en una etiqueta.
2. **CSS interno (embebido):** usando un bloque `<style>` dentro del `<head>` del documento.
3. **CSS externo:** usando un archivo `styles.css` enlazado con `<link rel="stylesheet">`.

## Archivos

- `index.html` — página principal con los tres ejercicios.
- `styles.css` — hoja de estilos externa (Ejercicio 3).
- `link.txt` — enlace al sitio publicado en GitHub Pages.
